# Объединение двух отсортированных списков

## 1. Проблема

Есть два списка числа в них идут по возрастанию. Нужно соединить их в один список, тоже по возрастанию.

## 2. Подход

Я сравниваю первые числа двух списков и беру меньшее. Потом снова сравниваю и снова беру меньшее. Когда один список заканчивается, я добавляю в конец всё, что осталось во втором.

Пример: 1, 2, 4 и 1, 3, 4.
Беру 1, потом 1, потом 2, потом 3, потом 4 Первый список закончился, добавляю оставшуюся 4.
Получается 1, 1, 2, 3, 4, 4.

## 3. Временная сложность

Временная сложность: O(n + m).

Я прохожу каждое число из двух списков один раз.

## 4. Пространственная сложность

Пространственная сложность: O(1).

Я не создаю новый список а только меняю ссылки.

## 5. Анализ / Улучшение

Более быстрого способа не вижу, потому что каждое число всё равно нужно посмотреть. Поээтому ничего не нужно и решение уже оптимальное.
