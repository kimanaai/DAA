# Цикл в связанном списке

## 1 Проблема

Есть связанный список. Нужно проверить есть ли в нём цикл nо есть не возвращается ли список сам в себя.

## 2Подход

Я иду по списку и запоминаю каждый узел, в котором уже была    Если я попадаю в узел который уже видела значит цикл есть. Если я дошла до конца списка значит цикла нет.

Пример: 3, 2, 0, -4, и после -4 снова идёт 2.
Прохожу 3 потом 2 потом 0 потом -4. Дальше снова попадаю в 2, а её я уже видела.
Получается true, цикл есть

## 3 Временная сложность

Временная сложность: O(n).

Я прохожу каждый узел списка один раз.

## 4 Пространственная сложность

Пространственная сложность: O(n).

Я запоминаю все узлы, которые прошла

## 5Анализ Улучшение

Есть способ лучше по памяти: два указателя, один идёт на 1 шаг, другой на 2. Если цикл есть, они встретятся. Тогда время будет O(n), а память O(1).
