# Sort an Array

## 1 Задача

Дан массив чисел. Нужно отсортировать его по возрастанию
без встроенных функций сортировки, за O(n log n).

## 2 Решение

Я использовала сортировку слиянием (merge sort).
Если в массиве один элемент или меньше, он уже отсортирован.
Иначе я копирую левую и правую половину в два новых массива,
сортирую каждую рекурсивно и сливаю их в один массив result.

При слиянии сравниваю первые элементы двух половин,
меньший кладу в result и сдвигаюсь дальше.
Когда одна половина закончилась, дописываю остаток другой.

```java
class Solution {
    public int[] sortArray(int[] nums) {
        if (nums.length <= 1) {
            return nums;
        }

        int mid = nums.length / 2;
        int[] left = Arrays.copyOfRange(nums, 0, mid);
        int[] right = Arrays.copyOfRange(nums, mid, nums.length);

        left = sortArray(left);
        right = sortArray(right);

        return merge(left, right);
    }

    int[] merge(int[] left, int[] right) {
        int[] result = new int[left.length + right.length];
        int i = 0, j = 0, k = 0;

        while (i < left.length && j < right.length) {
            if (left[i] <= right[j]) {
                result[k] = left[i];
                i++;
            } else {
                result[k] = right[j];
                j++;
            }
            k++;
        }

        while (i < left.length) {
            result[k] = left[i];
            i++;
            k++;
        }

        while (j < right.length) {
            result[k] = right[j];
            j++;
            k++;
        }

        return result;
    }
}
```

### Пример

Массив: [5, 2, 3, 1]

- Делю на [5, 2] и [3, 1].
- [5, 2] делю на [5] и [2], сливаю: [2, 5].
- [3, 1] делю на [3] и [1], сливаю: [1, 3].
- Сливаю [2, 5] и [1, 3]: беру 1, потом 2, потом 3, остаётся 5.

Ответ: [1, 2, 3, 5]

### Трудности

Сначала я попробовала сортировку вставками. Она работает,
но на LeetCode выдаёт Time Limit Exceeded, потому что её сложность O(n²),
а в массиве может быть до 50 000 чисел.

Ещё я забывала дописывать остаток половины после основного цикла,
и последние числа терялись.

## 3 Сложность

Время: O(n log n). Массив делится пополам примерно log n раз,
и на каждом уровне при слиянии обрабатываются все n элементов.

Память: O(n), потому что при делении и слиянии создаются новые массивы.

## 4 Можно ли лучше

Сортировка сравнением не может быть быстрее O(n log n).
Но числа в задаче ограничены (от -50 000 до 50 000), поэтому можно
использовать сортировку подсчётом (counting sort): посчитать,
сколько раз встречается каждое число, и выписать их по порядку.
Это даст O(n + k), где k это диапазон чисел.
