# Sort List

## 1 Задача

Дан связный список. Нужно отсортировать его по возрастанию
и вернуть начало отсортированного списка.

## 2 Решение

Я использовала сортировку слиянием.
Сначала нахожу середину списка двумя указателями:
slow двигается на 1 шаг, fast на 2 шага. Когда fast доходит до конца,
slow стоит на середине. Там я разрезаю список на две части,
сортирую каждую рекурсивно и сливаю их в один список.

При слиянии использую фиктивный узел dummy, чтобы было удобно
прицеплять узлы по порядку.

### Пример

Список: 4 -2 - 1 - 3

- Ищу середину: slow = 4, fast = 2. Сдвигаю: slow = 2, fast = 3.
  Дальше fast идти некуда. Режу после 2: получаю 4 - 2 и 1 - 3.
- 4 - 2 делю на 4 и 2, сливаю: 2 - 4.
- 1 - 3 делю на 1 и 3, сливаю: 1 - 3.
- Сливаю 2 - 4 и 1 - 3: беру 1, потом 2, потом 3, остаётся 4.

Ответ: 1 - 2 - 3 -4

### Трудности

Сначала я начинала fast с head, а не с head.next.
На списке из двух узлов он не делился пополам, и рекурсия
зацикливалась (StackOverflowError). С head.next всё заработало.

Ещё я забывала написать slow.next = null, и список не разрезался.

## 3. Сложность

Время: O(n log n). Список делится пополам примерно log n раз,
и на каждом уровне поиск середины и слияние проходят все n узлов.

Память: O(log n) на стек рекурсии. Новые узлы не создаются,
меняются только ссылки.

## 4. Можно ли лучше

По времени O(n log n) уже оптимально.
Память можно уменьшить до O(1), если делать слияние без рекурсии
(снизу вверх): сначала сливать куски по 1 узлу, потом по 2,
потом по 4 и так далее.
