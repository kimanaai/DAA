# Remove Linked List Elements

## 1Задача

Дан связный список и число val. Нужно удалить из списка все узлы,
у которых значение равно val, и вернуть начало нового списка.

## 2 Решение

Я решила задачу через рекурсию. Функция сначала очищает
остаток списка (всё после текущего узла), а потом решает,
оставить ли текущий узел. Если его значение равно val,
возвращаю то, что идёт после него. Иначе возвращаю сам узел.
Рекурсия останавливается, когда список закончился (head == null).

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        if (head == null) {
            return null;
        }
        head.next = removeElements(head.next, val);
        if (head.val == val) {
            return head.next;
        }
        return head;
    }
}
```



Список: 1 -2 -6 - 3 - 6, val = 6

Рекурсия сначала доходит до конца списка, потом возвращается назад:
- Последний узел 6: равен val, удаляем. Остаётся пусто.
- Узел 3: оставляем. Получается 3.
- Узел 6: равен val, удаляем. Остаётся 3.
- Узел 2: оставляем. Получается 2 → 3.
- Узел 1: оставляем. Получается 1 → 2 → 3.

Ответ: 1 -2 -3

### Трудности

Сложнее всего было с первым узлом: если он сам равен val,
непонятно, что возвращать. В рекурсии это решается само,
потому что функция просто возвращает head.next вместо head.

## 3 Сложность

Время: O(n), каждый узел обрабатывается один раз.
Память: O(n), потому что на каждый узел создаётся вызов рекурсии,
и все они хранятся в стеке, пока не дойдём до конца списка.

## 4Можно ли лучше

По времени быстрее O(n) нельзя. Но можно уменьшить память
до O(1), если решить задачу циклом: добавить фиктивный узел
перед head и идти по списку, пропуская узлы со значением val.
