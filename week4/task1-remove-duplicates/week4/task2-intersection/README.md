# Intersection of Two Linked Lists

## 1Задача

Даны два связных списка, которые могут соединиться в один общий хвост.
Нужно найти узел, с которого начинается общая часть, или вернуть null,
если пересечения нет.

## 2Решение

Сначала считаю длины обоих списков. Указатель длинного списка
сдвигаю вперёд на разницу длин, чтобы до конца оставалось одинаковое
количество узлов. Потом двигаю оба указателя по одному шагу,
пока они не укажут на один и тот же узел.

```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        int lenA = 0, lenB = 0;
        ListNode a = headA, b = headB;

        while (a != null) { lenA++; a = a.next; }
        while (b != null) { lenB++; b = b.next; }

        a = headA;
        b = headB;

        while (lenA > lenB) { a = a.next; lenA--; }
        while (lenB > lenA) { b = b.next; lenB--; }

        while (a != b) {
            a = a.next;
            b = b.next;
        }
        return a;
    }
}
```

### Пример

A: 4 → 1 → 8 → 4 → 5
B: 5 → 6 → 1 → 8 → 4 → 5 (общая часть с узла 8)

- Длины 5 и 6, сдвигаю b на один шаг: b = 6.
- a = 4, b = 6: разные.
- a = 1, b = 1: числа одинаковые, но узлы разные.
- a = 8, b = 8: один и тот же узел. Ответ: 8.

### Трудности

Сначала я сравнивала значения (a.val == b.val), и программа ошибочно
возвращала 1. Нужно сравнивать сами узлы (a == b).

## 3.Сложность

Время: O(m + n), каждый список прохожу не больше двух раз.
Память: O(1), использую только несколько переменных.

## 4 Можно ли лучше

Решение «в лоб» с вложенными циклами было бы O(m · n).
Мой вариант уже оптимальный. Можно сделать код короче
с помощью двух указателей, которые переходят на начало другого списка,
но сложность останется той же.
